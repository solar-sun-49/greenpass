# AI Traffic Management System – Setup & Execution Guide

## 1. Project Overview

This project is an AI-based Traffic Management System that uses a YOLO object detection model to detect vehicles from lane images and dynamically allocate traffic signal timings based on traffic density.

The system:

* Detects vehicles from 4 traffic lanes
* Categorizes vehicles into classes
* Calculates lane weight using PCU values
* Dynamically generates signal timings
* Can be integrated with Arduino for real-time traffic signal display

# 7. Vehicle Classification Logic

Vehicle categories are classified as:

| Vehicle Type               | Category |
| -------------------------- | -------- |
| Two-wheeler, Bicycle       | two      |
| Three-wheeler              | three    |
| Sedan, SUV, Hatchback, Van | four     |
| Truck, Bus, Heavy Vehicles | heavy    |

---

# 8. PCU (Passenger Car Unit) Values

| Category      | PCU Value |
| ------------- | --------- |
| Two Wheeler   | 0.5       |
| Three Wheeler | 1.2       |
| Four Wheeler  | 1.0       |
| Heavy Vehicle | 3.5       |

These values help estimate realistic traffic congestion levels.

---

# 9. Dynamic Signal Timing Logic

* Total traffic cycle = 120 seconds
* Lane timings are calculated proportionally using lane weight
* Minimum green time = 15 sec
* Maximum green time = 60 sec

This ensures fair and adaptive traffic signal allocation.

# 11. Common Errors & Solutions

## Error: No module named ultralytics

Solution:

```bash

```

## Error: Model file not found

Ensure the model path is correct:

```python
YOLO("UVH-26/weights/YOLOv11-S/UVH-26-MV-YOLOv11-S.pt")
```

Ensure lane images are present in:

```text

```
